# CP-07 本地截图、短片与弹幕导出

## 使用与限制

- 两项默认关闭。截图与短片需要针对当前视频明确确认有权保存。生成后点击面板内的本地下载链接。离开房间、更换视频源或关闭开关会清理待下载文件和录制资源。
- PNG 最长边限制为 3840 像素。WebM 可手动停止，最长 10 秒，达到 16 MiB 上限时停止并丢弃。遇到受保护媒体、跨域限制或浏览器不支持时显示原因。短片使用 WebM，弹幕使用 TXT。
- 弹幕导出在内存中保留当前房间最多 500 条已观察的正文。TXT 每行包含 UTC 观测时间和正文。昵称、房间编号以及其他标识不进入文件。切换房间或关闭开关会清除记录。
- 沿用原有脚本权限。文件通过浏览器本地对象 URL 提供，录制结束只释放录制拥有的轨道。[媒体录制规范](https://w3c.github.io/mediacapture-record/)

## 验证

2026-11-08（悉尼），Chrome 156.0.8078.49 和 Edge 156.0.4314.58 使用正式构建、模拟 Tampermonkey API 和自建视频。两款浏览器均验证 PNG、WebM、带表情和时间戳的 TXT 下载及文件签名，停止录制后原视频继续播放。Chrome 覆盖 10 秒自动停止，Edge 覆盖手动停止。跨域拒绝、加密事件和房间切换由自动化覆盖。
