# CP-03 页面清理与按房间保存

## 范围与回退

- 页面清理只在数字直播间启用。各项默认关闭。展馆横幅、礼物选项、礼物特效和飘条分别通过版本 1 的直播房间选择器定位。遇到不匹配或包含受保护控件的区域时保留原样。
- 简洁移除动态背景，影院压暗动态背景，深色调整房间底色。三种模式沿用站点的播放器和聊天布局规则。简洁开启时，动态背景保持隐藏。
- 房间清理偏好独立保存。换房立即应用目标房间的偏好，刷新后保留。CP-02 的全局 JSON 格式沿用原有版本，房间编号和房间偏好不进入导出。
- **恢复原始布局**关闭当前房间的全部清理开关并移除脚本样式。安全模式可停用脚本界面和增强，并保留偏好供下次启用。此次沿用 CP-01 的脚本权限。

## 实机复验

1. 用 Tampermonkey 安装正式构建，选择有礼物栏和没有礼物栏的房间，检查每个可匹配的清理项。
2. 逐个启用和关闭清理项，核对播放、关注、聊天、举报和充值控件仍可使用。开启清理项后再关闭，确认样式当场恢复。
3. 给两个房间保存不同组合，来回换房并刷新。点击 **恢复原始布局**，确认仅清空当前房间的清理偏好。
