# CP-02 设置面板与交互框架

## 范围与回退

- 在抖音直播首页和数字房间显示一个悬浮入口。宽窗口中如果播放器右侧留有空间，入口停靠在播放器旁；其他布局使用视口右下角。面板独立滚动，关闭后仅保留入口。
- 支持紧凑面板和只读视频元素诊断，两者默认关闭。页面清理、播放器控制、弹幕过滤、截图和录制由后续检查点实现。视频诊断只报告页面是否存在 `video`，播放能力由 CP-00 验证。
- Tampermonkey 存储中保存已实现功能的布尔偏好。导入仅接受版本 1 的已知偏好；导出内容只包含偏好和格式版本。偏好变更在当前标签页立即生效，其他已打开的标签页可在刷新后读取。安全模式独立保存，不参与导入和重置。
- 关闭单项会立即恢复它的视觉效果并释放相关监听。Tampermonkey 菜单中的安全模式可移除整套界面和增强，之后可从同一菜单恢复。脚本沿用 CP-01 权限。

## 实机复验

1. 在 Chrome 和 Edge 的 Tampermonkey 中安装正式脚本，各打开直播首页和两种实际房型。检查入口数量、位置和原生播放控件。
2. 用 Tab 聚焦入口并按 Enter。确认焦点进入设置面板，再用 Esc 关闭并回到入口。
3. 开启两个可用开关，换房并刷新。关闭诊断后确认视频元素提示消失。导出偏好，恢复默认，再导入并确认开关状态恢复。
4. 缩窄窗口检查面板可滚动。开启安全模式后确认悬浮入口与观察器均清理，原生页面仍可操作。
