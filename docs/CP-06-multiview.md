# CP-06 画中画与双房间视图

- 两项默认关闭。画中画由用户点击触发，浏览器或视频未开放时提示使用网页播放器。换房或关闭功能时退出由脚本开启的画中画。
- 双房间视图最多加载两个独立的抖音网页版数字房间。内嵌由浏览器和站点策略决定，未就绪时可在新标签打开。房间链接只在视图打开期间使用。
- 新窗格默认静音，只有一个窗格可由用户开启声音。切到后台时暂停所有窗格。从直播间打开视图时暂停当前播放器，关闭后可用原生控件恢复。交换位置保留内嵌文档，关闭则释放视频和 iframe。
- 18 项冒烟测试通过。覆盖 PiP 不可用回退与生命周期、房间 URL 校验、两格上限、重复房间、交换位置、关闭和换房。权限沿用 CP-01。

## 验证记录

2026-11-08（悉尼），Chrome 156.0.8078.49 用正式构建与模拟 Tampermonkey API 在两个未登录公开房间验证了双路播放、默认静音、单路声音与无刷新交换。

- 首轮 25 组采样确认两路持续推进，随后有一路未通过跨采样的时间比较。该轮记录不足以区分时间轴重置与播放中断。
- 第二轮每 30 秒在同一采样窗口比较两路的解码帧计数和播放时间。900 秒内全部 30 组确认两路播放推进、保持静音。关闭一格和关闭整个视图后，对应 iframe 均已卸载。
- Chrome 和 Edge 的自建视频夹具验证了原生画中画进出、后台暂停、关闭清理，以及 CSP 阻止嵌入时提供新标签入口。

未登录或不允许嵌入的房间仍受原网页限制。[抖音网页版直播入口](https://live.douyin.com/) · [浏览器画中画规范](https://w3c.github.io/picture-in-picture/)

实机复验时在 Chrome 安装正式脚本，添加两间稳定播放的房间。播放 15 分钟后先关一格，再关视图，确认两次均释放对应 iframe。登录态与实际扩展安装待复验。
