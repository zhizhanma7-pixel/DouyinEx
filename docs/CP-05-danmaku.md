# CP-05 只读弹幕过滤

- 默认关闭。开启后读取原生聊天列表里的普通文本行。关键词和显示偏好保存在本机，关闭功能即可撤销样式。隐藏采用保留行高的方式，便于虚拟列表维持滚动位置。
- 观察范围为聊天列表尾部最多 180 行。行复用后以新内容生成会话内标识。时间戳记录浏览器首次看到该条内容的时间。输入框、IME 与发送按钮交给原生页面。+1 和小尾巴由独立检查点处理。
- 2026-11-08（悉尼），Chrome 156.0.8078.49 的未登录公开房间可见列表容器，观察窗口内没有普通文本行。登录态、繁忙房间和真实 Tampermonkey 安装待复验。
- 自动化使用独立编写的模拟 DOM，覆盖昵称和正文分离、表情、隐藏节点、重复与关键词、虚拟行复用、180 行上限、滚动与 IME 隔离。已知 DOM 类名参考公开页面与现有脚本的兼容标记。[公开页面](https://live.douyin.com/) · [兼容标记参考](https://greasyfork.org/en/scripts/570262-douyin-live-cleaner/code)

复验时使用真实登录态进入繁忙房间，观察新消息、滚动、折叠列表和换房。检查筛选与原生输入同时可用，再关闭开关确认样式恢复。
