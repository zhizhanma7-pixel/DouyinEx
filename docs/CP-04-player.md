# CP-04 播放器增强

## 范围与回退

- 数字直播间中的四个播放器增强开关默认关闭，偏好在本机保存。面板从可见的原生视频读取播放状态、尺寸和音量。未识别播放器或尚无视频时，面板动作停用。
- 画质读取网页菜单中的标清、高清、超清、蓝光和原画。带权限提示、禁用或无法识别的菜单项会被跳过。未登录实测中，网页拒绝了带隐藏「登录即享」提示的档位，因此这些档位也交由原生菜单处理。显示当前画质和实际视频尺寸，切换反馈以网页菜单更新为准。最高画质偏好在每次进房时最多尝试一次。
- 滚轮只在视频画面内调整音量，按住修饰键、在播放器控件或聊天区滚动时交给网页和浏览器。静音时可以预调音量。
- 防误暂停仅处理播放中直接落在视频画面上的指针单击。暂停仍可通过原生播放按钮操作。填满画面按比例裁切视频，关闭功能或换房时恢复。全屏需要主动点击，可按 Esc 或从原生控件退出。
- 可关闭各开关或进入安全模式。需要撤回已执行的画质或音量调整时，可用网页原生控件调回。沿用 CP-01 的脚本权限。

## 实机复验

1. 在 Chrome 和 Edge 的 Tampermonkey 中安装正式构建，打开横屏和竖屏直播间，查看实际提供的画质和状态。
2. 手动切换到较低档位，再启用最高画质偏好。确认网页确认切换后继续播放，手动选择另一档后同一房间不会被反复覆盖。
3. 在画面上与聊天区分别滚动。切换防误暂停后验证直接点击画面和原生播放按钮的行为。试用填满画面和全屏并恢复。
4. 换房并重复启用和关闭开关，检查音量每次只调整一步。在媒体或画质菜单不可用时确认对应动作停用。
