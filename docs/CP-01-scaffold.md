# CP-01 项目骨架与页面生命周期

CP-01 按维护者要求先行实施。CP-00 的目标网络播放验证仍待执行。CP-01 的自动化检查和实机验收分别记录。

## 支持范围

- 入口为 `https://live.douyin.com/` 顶层页面。路由识别首页与数字房间路径，忽略查询参数和片段。其他路径不挂载页面功能。
- 使用 Tampermonkey 的 `urlchange` 事件监听站内导航，并通过 `popstate` 处理历史记录导航。缺少 `urlchange` 支持时，每 500 毫秒检查当前路由。离页或进入安全模式时停止监听，浏览器从往返缓存恢复页面时重新读取设置。[Tampermonkey 路由事件文档](https://www.tampermonkey.net/documentation.php?locale=en&q=window)
- 脚本权限仅包括路由事件、读取与写入设置、注册与移除菜单。只保存安全模式布尔值。诊断日志只记录预定义错误代码。脚本不发出网络请求。
