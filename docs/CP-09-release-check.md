# CP-09 简易发布检查

## 安全与构建

- `pnpm install --frozen-lockfile` 使用固定依赖，`pnpm check` 执行 lint、类型检查、冒烟测试和构建。`pnpm audit --audit-level high` 作为 CI 高危依赖门槛。
- `pnpm verify-build` 用同一工具链重建并逐字节比对正式脚本，然后生成 SHA-256 校验文件。构建和校验文件由 CI 一起提供。
- 审查范围包括 Tampermonkey 权限、网络、存储和 DOM。脚本匹配抖音直播域名，使用站内路由、菜单及设置权限。双房间入口仅加载用户选择的同站直播间，下载链接使用本地 Blob。
- 设置、关键词和房间偏好保存在本机。弹幕观察数据仅在会话中保留。页面文本以文本节点呈现，源代码审查未发现脚本读取凭据、遥测上报或执行远程脚本的路径。安装包附 MIT 文本。
