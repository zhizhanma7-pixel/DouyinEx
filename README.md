# DouyinEx

面向抖音网页直播的 Tampermonkey 增强脚本。

> 当前状态：规划阶段。尚未完成浏览器端可用性验证（CP-00），也尚未发布可安装版本。

## 开发工作流

- [CHECKPOINTS.md](./CHECKPOINTS.md)：CP-00 至 CP-09 的完整实施顺序、依赖、验收条件及 Codex 工作规范。
- **弹幕 +1：CP-05.1**（手动选取弹幕并发送／草稿回退）。
- **弹幕前缀 / 后缀：CP-05.2**（小尾巴，兼容 Enter、按钮和 +1）。

开发采用浏览器优先方案。首先验证 [抖音网页版直播](https://live.douyin.com/) 在实际直播间的持续播放和交互情况，再开始代码实现。

## 状态说明

各项 Checkpoints 当前均未通过验收。项目目标是复刻 DouyuEx 的网页观看体验，而不是直接复用斗鱼专属接口或自动绕过抖音客户端限制。
