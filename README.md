# DouyinEx

面向抖音网页直播的 Tampermonkey 增强脚本。

DouyinEx 在直播首页和数字房间提供悬浮设置入口。可增强原生播放器、查看视频元素状态，也可为每个直播间单独设置页面清理和布局。

## 开发工作流

- 开发以 GitHub 默认分支的 [CHECKPOINTS.md](CHECKPOINTS.md) 为准。该文件记录 CP-00 至 CP-09 的实施顺序、依赖和验收条件。
- **CP-05.1 弹幕 +1** 与 **CP-05.2 小尾巴**已实现，尚待真实登录房间验收。

## 构建和试装

使用 Node.js 24 和 pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm verify-build
pnpm build:dev
```

- `pnpm check` 依次执行 lint、类型检查、模拟页面测试和正式构建。产物是 `dist/douyinex.user.js`，也可从通过检查的 GitHub Actions 运行下载。
- `pnpm verify-build` 比较当前产物与源码重建结果，并生成 SHA-256 校验文件。CI 会同时检查高危依赖问题并上传两份文件。
- `pnpm build:dev` 生成带内联源码映射的 `dist/douyinex.dev.user.js`。
- 在 Tampermonkey 中新建脚本，将正式产物的全部内容粘贴进去并保存，然后刷新抖音直播网页。在 Tampermonkey 菜单中可以开启或关闭 DouyinEx 安全模式。切换立即作用于当前标签页，刷新后保留。

## 使用设置面板

- 点击悬浮的 **DouyinEx** 按钮打开设置。键盘可用 Tab 和 Enter 操作，Esc 关闭并将焦点返回入口。
- 可用开关默认关闭，修改立即生效，换房和刷新后保留。展开 **高级 → 导入、导出与恢复**，可通过文本框复制或粘贴偏好 JSON，也可恢复默认值。
- 在直播间的 **播放** 中开启 **播放器快捷控制**，查看播放状态、视频尺寸和音量，并使用网页提供的画质、播放器全屏和填满画面。**优先最高可用画质** 每次进房最多尝试一次，之后仍可手动调整。
- **播放器滚轮音量** 在视频区域内每步调整 5 个百分点。**防误暂停** 防止单击正在播放的视频画面时意外暂停。
- 在 **弹幕** 中开启 **弹幕过滤**，可保存屏蔽关键词、隐藏重复文本或调低弹幕亮度。关闭开关后恢复原有弹幕样式。
- 在 **弹幕** 中开启 **弹幕 +1**。鼠标移到直播画面里的滚动弹幕上时，该条弹幕暂停并显示 **+1**，移开后继续滚动。点击 **+1** 把正文和有文字标记的表情填进输入框，再手动发送。画面弹幕取自开启后收到的聊天消息，关闭功能会恢复原生画面弹幕。右侧聊天列表也支持 **+1**，原有草稿可用 **恢复原草稿** 找回。
- **弹幕小尾巴**：设置前缀或后缀内容（最多 20 字），按 Enter 或点发送按钮时自动加上，且只加一次。输入法选字、Shift+Enter 和空消息不受影响，超出字数时本条不加。可勾选 **暂时不加**。
- **弹幕统计** 显示当前房间新识别的文本条数、观测时长和估算频率。统计在换房后重置。[统计口径与功能对照](docs/CP-08-stats.md)
- 在 **多媒体** 中可使用浏览器画中画，或打开双房间视图并添加两个房间。内嵌房间默认静音，可交换位置或单独关闭。若无法内嵌，可用同一行的链接在新标签打开。
- **截图与录制** 需确认有权保存当前内容。浏览器允许读取视频时，可生成 PNG 或最长 10 秒的 WebM。**观察与导出弹幕** 可生成带观测时间的 TXT，最多保留本次房间的 500 条文本。
- 在直播间的 **页面清理** 中可隐藏展馆推广横幅、礼物选项栏、礼物特效和飘条，也可开启简洁、影院或深色布局。清理偏好只对当前直播间生效。点击 **恢复原始布局** 可立即清除这个房间的清理偏好。
- 导入和导出仅包含全局偏好。房间编号和房间清理偏好保存在本机，只保留最近使用的 50 个房间，恢复为默认的房间不再占用存储。在 **高级 → 导入、导出与恢复** 中可 **清除所有房间设置**。
- 遇到页面布局冲突时，可关闭面板，或从 Tampermonkey 菜单开启安全模式以移除悬浮入口并停用功能。
